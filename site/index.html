Windows · .NET 8 · Avalonia · ViGEmBus

A virtual controller you can drive from keys, mouse and the network

GamepadEnhancer creates a virtual Xbox 360 or PS4 controller. Keys, mouse buttons and the wheel press its buttons, mouse movement can drive the right stick, and another program such as Axiom can drive every stick, trigger and button over the Network API.

What it does

Six things, one virtual pad

Network API

Let another program on your network drive the sticks, triggers and buttons with MAKCU-style commands over TCP. Token protected and off by default.

Mouse look

Turn mouse movement into right-stick movement, with sensitivity, response curve, game dead zone and release time.

Live monitor

See the pad as it is sent: physical input, processed input or the final report, as an Xbox or DualShock 4 picture.

Keys to buttons

Bind keyboard keys to 16 controller actions, with optional turbo (rapid fire) from 1 to 30 Hz.

Two input readers

Windows low-level hooks or Raw Input with background capture. One at a time, with held keys released when you switch.

Profiles

Save everything as JSON profiles. A Default.json ships inside the app and is the starting point on a fresh install.

Quick start

Up and running in five steps

  1. Install ViGEmBus (the driver that makes virtual controllers). Download it from its releases page.
  2. Download the zip from the latest release and extract it anywhere you can write to. You need the .NET 8 runtime (the zip is framework-dependent).
  3. Run GamepadEnhancer.exe, pick PS4 or Xbox 360 in the header, and click Connect.
  4. Check the output without a game: press Win+R, run joy.cpl, pick the virtual controller, open Properties, then the Test tab. The right stick shows as the second pair of axes (Z Axis and Z Rotation on a PS4 pad).
  5. Pick settings in your game's controller options and tune the sliders. Save the result as a profile.
Good to know

Three things worth reading first

It does not move your mouse

The app only reads your mouse and keyboard. Its output is a virtual controller: stick values and buttons sent through ViGEm. Nothing is injected into the mouse or keyboard, so the cursor never moves from this app. A game turns stick deflection into camera speed, not into a position.

Games that run as administrator

Windows hides mouse and keyboard events from a normal app while an elevated window is in front. If your game runs as administrator, run this app as administrator too, or your bound keys and mouse buttons will not register.

Check the game's rules

Tools that shape controller input can break the terms of service or anti-cheat rules of online games, and accounts have been banned for it. This project is documented for learning and single-player or private use. You are responsible for how you use it.
