The profile file

These are the fields in the shipped Default.json. Missing fields take their built-in defaults.

{
  "Name": "Default",
  "ControllerType": "PS4",
  "KeyBindings": { "A / Cross": "None", "...": "..." },
  "TurboEnabled": { "A / Cross": false, "...": "..." },
  "TurboHz": { "A / Cross": 12, "...": 12 }
}

Older profiles may still contain drift, filtering, recoil and disengage fields. They are ignored when loading and left out when saving.

Network API

The Network tab lets another computer drive the virtual pad with MAKCU-style text commands over TCP. It is off by default and every client must send auth <token> first. The same app can also send its pad to another PC, so the mouse-and-keyboard PC and the game PC can be different machines.

CommandEffect
km.controller(id,value[,hold_ms])Set one control (buttons 0-9 and 16-19, triggers 10-11 as 0-1023, sticks 12-15 as -32768 to 32767, +Y down). hold_ms releases it afterwards.
km.controller_clear()Release everything set remotely.
km.version(), km.api_version(), km.echo()Identification and echo.
Keep the port private

Anyone on your network with the token controls the pad, and the traffic is not encrypted. Use the "this PC only" option, a firewall, or a VPN. The button ids 0-9 and 16-19 are this app's own mapping, not confirmed against MAKXD firmware. Full details: docs/NETWORK_API.md.

FAQ and troubleshooting

The game does not react at all

Check that ViGEmBus is installed and the app says Connected. Open joy.cpl and confirm the stick moves there. If it does, check the game's controller settings and that it is using the new pad.

My bound keys or mouse buttons do nothing

If the game is elevated, run this app as administrator. Windows blocks hook and Raw Input events from lower-privileged apps to elevated windows. Also try the other Input capture method.

How do I make the stick move from another program?

Turn on the Network API (Network tab), connect the controller, and send auth <token> then km.controller(14,16384) style commands over TCP. Axiom does this for aiming and recoil.

Stick Y looks inverted on Xbox 360

On Xbox 360 positive Y is up and on DS4 it is down. Network API stick values follow one convention (+Y down) and the app converts them. Raw axis numbers in tools show the real sign.

Does it move my mouse?

No. It only reads mouse and keyboard, and its output is a virtual controller.

Will I be banned?

Possibly, in online games that forbid input tools. This project gives no guarantee about any game's rules. Read the game's terms and use it only where it is allowed.

Glossary

ViGEm / ViGEmBusVirtual Gamepad Emulation framework and its Windows driver that creates virtual controllers.
DS4DualShock 4, the PS4 controller. Axes run 0 to 255.
TickOne pass of the engine loop (10 ms).
HeartbeatA repeated report every 250 ms when nothing changed, so the game keeps seeing a live pad.
Raw InputA Windows API that delivers device input directly to a window, even in the background.
Synthetic inputInput produced by software rather than a physical device.
