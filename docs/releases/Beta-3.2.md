## Beta 3.2

### New config: Default (Xbox 360)
- A second built-in default in the **Config** list, right after **Default (PS4)**: the Xbox to keyboard + mouse layout. It uses the same keys as the PS4 Default (left stick `W A S D`, right stick = mouse, LS = `Shift`, RS = `V`, RT / LT = Left / Right Mouse, RB = `G`, LB = `Q`, A = `Space`, B = `C`, X = `R`, Y = mouse wheel up, D-Pad = `1 2 3 4`, Menu = `Esc`) with **View (Back) = `M`**.
- The virtual Xbox 360 pad has no Share button or touchpad, so `F12` and the touchpad key are not bound in it. Picking it selects the Xbox 360 output type when no pad is connected.
- **Default** is now named **Default (PS4)**.
- Where a binding listed alternatives (for example `V` or Middle Mouse), the first one is used; the others are one click away in the picker.
