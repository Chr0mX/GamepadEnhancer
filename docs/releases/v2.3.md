## GamepadEnhancer v2.3

Requires Windows 10/11, ViGEmBus and the .NET 8 Desktop Runtime. Unzip anywhere you can write to and run `GamepadEnhancer.exe`. Builds on v2.2.

### The app now shows its real version
The version in the header was stuck at `v1.1.0-beta` in every release since then. It now reads `v2.3`, matching the release, and a test fails the build if the app version and the newest release notes ever disagree again.

### Dashboard: live state first
The dashboard opens on the controller picture (pressed buttons light up), then the left and right stick plots, the triggers and the button event stream. The virtual controller card and the details card come after. Cards reflow to two columns and one column on narrower windows.

Profiles, settings and the controller engine are unchanged.
