## GamepadEnhancer v2.1

Requires Windows 10/11, ViGEmBus and the .NET 8 Desktop Runtime. Unzip anywhere you can write to and run `GamepadEnhancer.exe`. Builds on v2.0.

### Dashboard in the ControllerMeta layout
The dashboard now follows the card order of the open [ControllerMeta](https://github.com/HK560/ControllerMeta) frontend on a twelve-column grid with 12 px gaps: left and right stick plots (a fading trail of the final stick output with the current point), the virtual controller card (state, output rate, type, path), a details card with key / value rows (game config, profile, physical pad, network API, capture, mouse look, paddles, blocking), then the controller picture, trigger bars and the button event stream. Every value is real engine data and reads zero while nothing is connected. Cards reflow to two columns and one column on narrower windows.

### Fonts verified
The bundled Inter and JetBrains Mono are now covered by a test that fails if the app silently falls back to a system font.

Colours, shapes and sizes are unchanged from v2.0 (the ControllerMeta design tokens). Settings, profiles, presets and the controller engine are unchanged and still load.
