## GamepadEnhancer v1.4

Requires Windows 10/11, ViGEmBus and the .NET 8 Desktop Runtime. Unzip anywhere you can write to and run `GamepadEnhancer.exe`. Builds on v1.3.

## Beta 2.9

### Apex layout and a default PS4 to remap
- The keyboard + mouse layout is now its own built-in profile, **Apex** (nothing in it changed). The app starts on it, and it cannot be overwritten or deleted: change it, then save under another name.
- **Default** is a plain PS4 pad with nothing bound and mouse look off, ready to be remapped. It is saved as `profiles/Default.json` like any profile.
- An **Apex** toggle on the top bar switches between the two.
- Upgrading replaces an existing `profiles/Default.json` once with the empty Default; your previous file (for example the v1.3 default) is kept as `Default.json.bak` (or `.bak2`, ...). Your own profiles are not touched.

### Also
- The Xbox button names are gone from the Buttons card; buttons show PlayStation names. The Xbox 360 output type is unchanged.

### Known
- Not yet run on Windows hardware; the build and unit tests run on CI.
