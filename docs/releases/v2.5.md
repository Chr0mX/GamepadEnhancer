## GamepadEnhancer v2.5 MIX (beta)

A preview build from the `MIX` branch, with its own version number (`2.5.0-mix`). It is built on v2.4 and adds the first part of the advanced binding system. Requires Windows 10/11, ViGEmBus and the .NET 8 Desktop Runtime. Unzip anywhere you can write to and run `GamepadEnhancer.exe`.

### New: Bindings page
A binding connects one input (a key, a mouse button or a wheel notch) to one or more outputs (virtual pad buttons, triggers with a percentage, keyboard keys, mouse buttons).
- **Seven conditions:** Held, Unheld (repeat); Press, Release, Double, Tap, Hold (run once). Change it with the selector on the row; Double, Tap and Hold times are under Details.
- **Toggle:** latches a run-once binding on and off. The first activation starts it, it keeps running after you let go, the next activation stops it.
- **Running state:** a row is highlighted only while the binding is really running (taken from the engine, not from the on/off switch). A toggled binding shows a green border while latched. Rows say Waiting for input, Running, Toggled active, Waiting for hold, Waiting for double press, On another layer, Disabled, or Not connected.
- **Output safety:** two bindings can share an output without releasing each other's; everything is released on disconnect, shutdown, editing or deleting a binding.
- **Turbo:** pulse a binding's outputs 1-30 times per second while it runs.
- **Layers (shift):** a binding on Layer 1-3 runs only while that layer is switched on by a shift binding, and takes over its input from the base binding meanwhile. A Layer binding with no outputs un-maps its input. There is a short "How layers work" explanation on the page.
- Copy / paste a binding, "Press a key..." to pick the input, a warning when an output does not exist on the selected pad, and your normal mappings stay as the automatic bindings (a manual binding on the same input turns that mapping off).
- Saved with the profile (optional block, older profiles are unchanged).

### Known
- Built and tested headless on CI. **Not tried with real hardware** (real mouse, keyboard, virtual pad), and the new page has not been seen on a real screen.
- Analog bindings (mouse movement) only report "running" for now. Aim settings, curves, smoothing, thumbstick and physical controller input are not part of this build.
- Condition timing runs on the 10 ms output tick, so Tap, Double and Hold are accurate to about 10 ms.
