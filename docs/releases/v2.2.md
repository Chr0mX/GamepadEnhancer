## GamepadEnhancer v2.2

Requires Windows 10/11, ViGEmBus and the .NET 8 Desktop Runtime. Unzip anywhere you can write to and run `GamepadEnhancer.exe`. Builds on v2.1.

### One profile menu
Profiles are now managed from a single menu instead of a list, a name box and four buttons. The header shows `Game · Profile` (with a dot when you have unsaved changes) and opens the menu: pick a profile to load it, or Save, Save as, Duplicate, Rename, Delete, Import, Export, Open profiles folder, and Reset the game to its defaults. The Games page has the same menu on a button, which is also the way in on narrow windows.

- Loading another profile while you have unsaved changes asks first.
- `Default` cannot be renamed or deleted.
- Switching game clears the loaded profile, since a profile belongs to the game it was loaded in.
- Wording is now consistent: **Game**, **Profile**, **Controller**. "Game configs" became "Games".

Profile files and their format are unchanged; existing profiles show up in the menu as they are.
