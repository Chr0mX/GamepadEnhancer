## GamepadEnhancer v1.8

Requires Windows 10/11, ViGEmBus and the .NET 8 Desktop Runtime. Unzip anywhere you can write to and run `GamepadEnhancer.exe`. Builds on v1.7.

### Complete interface redesign
- A sidebar replaces the crowded header and tabs. The virtual controller type and Connect / Disconnect are always in the sidebar footer; a status bar shows the connection and the loaded config.
- **Dashboard**: virtual controller, output path (ViGEm or another PC), physical controller, Network API, the active game config and profile, and the state of mouse look, paddles, input blocking and capture.
- **Controller**: the diagram is the main view, with an Xbox 360 / PS4 switch above it and the editor beside it. The Xbox diagram is redrawn.
- **Games**: pick a config; see whether it is a built-in default or has your saved changes, where its defaults come from and what the game does on each button.
- **Rear paddles**: a large rear view with the four paddles, an overview with live "held" indicators and the hardware paddle each slot reads.
- **Mouse look**, **Profiles** (with per-file details), **Monitor**, **Network** (Receive and Send are now separate sections) and **Input & settings** (capture method, blocking, appearance, data folders).
- One consistent design system: dark first with a light theme, one accent colour, shared components and a visible keyboard focus ring. The window collapses its sidebar and stacks columns when narrow.

Settings, profiles, presets and the controller engine are unchanged and still load.

### Known
- The new layout was built and tested headless on CI (the window opens and every page loads at three sizes) but not looked at on a real screen, so spacing may need tweaks.
- Number entry still uses numeric boxes (no sliders); the Network page does not show remote command counters. Warzone's native layout is still unverified.
