## GamepadEnhancer v1.0 (beta)

First release as an independent project. GamepadEnhancer creates a virtual Xbox 360 or PS4 controller with ViGEm and applies base stick drift, right stick filtering, recoil patterns and PC-key-to-controller bindings. It can also accept MAKCU-style `km.controller(...)` commands over TCP and stream this PC's mouse buttons over UDP.

### Requirements
- Windows 10/11 with **ViGEmBus** installed
- **.NET 8 Desktop Runtime** (the build is framework-dependent)

### Install
Unzip `GamepadEnhancer-win-x64-v1.0.zip` anywhere you can write to and run `GamepadEnhancer.exe`. See the README for ViGEm and MAKCU setup.

### Notes
- Beta: the build passes CI, but the Network API and the mouse button UDP stream have not been run end to end on Windows yet.
- No dependency on Axiom or any other app.
