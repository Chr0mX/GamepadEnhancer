## GamepadEnhancer v1.7

Requires Windows 10/11, ViGEmBus and the .NET 8 Desktop Runtime. Unzip anywhere you can write to and run `GamepadEnhancer.exe`. Builds on v1.6.

### Default (Xbox 360) config
A second Default in the Config list, **Default (Xbox 360)**: the same keyboard + mouse table as Default (PS4), with View = `M` and Menu = `Esc`. The virtual Xbox 360 pad has no Share button or touchpad, so `F12` is unbound.

### Choose any key
Binding pickers have a **Press a key or button** capture (keys, mouse buttons, wheel notches; rear paddles and stick directions too), and the key list is much larger (Insert/Delete/Home/End/Page Up-Down, Caps Lock, Print Screen, Pause, numpad, punctuation, F13-F24).

### Controller-independent naming (Beta 3.3)
- Controls have neutral canonical ids (`FACE_SOUTH`, `LB`, `PADDLE_LEFT_UPPER`, ...); the names Cross / A etc. come from per-controller data files, so labels, binding titles and the diagram follow the selected controller.
- Games define actions (`JUMP`, `RELOAD`, `TACTICAL`, ...) and where their native layout puts them; profiles can reference those actions. See [docs/ARCHITECTURE.md](../ARCHITECTURE.md).
- Existing profiles, presets and paddle settings load unchanged and are saved in the new format.

### Known
- Not run on Windows hardware; build and 176 unit tests pass on CI. Warzone's native layout is still not verified. Editing by game action in the UI is not built yet.
