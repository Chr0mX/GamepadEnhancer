## GamepadEnhancer v2.0

Requires Windows 10/11, ViGEmBus and the .NET 8 Desktop Runtime. Unzip anywhere you can write to and run `GamepadEnhancer.exe`. Builds on v1.9.

### Interface aligned with the ControllerMeta design system
The interface now uses the same design tokens as the open frontend of [ControllerMeta](https://github.com/HK560/ControllerMeta): its colours (dark `#0F1117` page, `#1A1D27` cards, `#2A2E3E` borders, blue `#4F8CFF`, green `#34D399`, red `#F43F5E`, orange `#FB923C`, purple `#A78BFA`, plus its light theme), its shapes (12 px cards with a hover accent border, 8 px tiles, 4 px buttons and inputs, 44 px rail items), its sizes (64 px rail, 56 px header, 16 px page padding, 12 px gaps, a 10 / 11 / 12 / 14 / 18 / 24 px type scale) and its fonts: **Inter** and **JetBrains Mono**, now bundled with the app (SIL Open Font License). No code, assets or branding were copied.
- Dashboard: cards of metric tiles with coloured monospace values (output rate, virtual controller state, triggers and sticks on the final output, a live button event stream).
- Icon rail, a header with version, state dot and tags (VIGEM, HOOKS, NET API), underline tabs inside pages.
- Mouse look and Monitor settings are sliders paired with number boxes; the mouse page has a response-curve plot and a live stick scope.

Settings, profiles, presets and the controller engine are unchanged and still load.

### Known
