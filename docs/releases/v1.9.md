## GamepadEnhancer v1.9

Requires Windows 10/11, ViGEmBus and the .NET 8 Desktop Runtime. Unzip anywhere you can write to and run `GamepadEnhancer.exe`. Builds on v1.8.

### A denser, instrument-style interface
- **Dashboard** is now a grid of compact metric tiles with coloured values: virtual controller (state, output rate in reports/s, type, path), inputs and network, active configuration, triggers and sticks (live bar meters and values on the final output), the controller picture, and a live button event stream. Everything shown is real engine data; it reads zero while nothing is connected.
- **Navigation**: a narrow icon rail, a slim header with the app version, a state dot and small tags (VIGEM, HOOKS, NET API), and underline tabs inside pages (Controller: Mapping / All bindings; Network and input: Receive / Send / Input and blocking / Appearance and files).
- **Mouse look**: every numeric setting is a slider paired with a number box; a response-curve plot drawn with the engine's own function and a live right-stick scope show what your curve and dead zone do.
- **Monitor**: every numeric setting has a slider and a number box; the three pipeline stages sit side by side.
- Flatter, tighter look: 28 px controls, square-ish corners, flat panels with a banded title, monospace values.
- The Xbox 360 diagram is redrawn; the dashboard shows a read-only live picture of the pad.

Settings, profiles, presets and the controller engine are unchanged and still load.

### Known
- The layout is built and tested headless on CI (the window opens, every page loads and no page needs sideways scrolling at four window sizes) but has not been looked at on a real screen, so spacing and colours may need tweaks.
- Warzone's native layout is still unverified.
