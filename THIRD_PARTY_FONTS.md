# Bundled fonts

The app bundles two open fonts so the interface looks the same on every machine. Both are licensed under the SIL Open Font License 1.1; the licence texts are next to the font files in `src/GamepadEnhancer/Assets/Fonts/`.

- **Inter** (Regular, Medium, SemiBold, Bold, Black), by Rasmus Andersson: https://github.com/rsms/inter (v3.19)
- **JetBrains Mono** (Regular, Medium, Bold), by JetBrains: https://github.com/JetBrains/JetBrainsMono
